# 🚀 Placement Prep Tracker

A sleek, all-in-one web app to streamline your placement preparation journey. Track DSA progress, manage company targets, log LeetCode problems, save interview experiences, schedule mock interviews, and maintain daily notes — all in one place.

---

## ✨ Features

- 📊 **DSA Tracker**
  - Track topic-wise progress (Not Started / In Progress / Done)
  - Visual progress bar

- 🎯 **Company Wishlist**
  - Categorize companies into Dream, Target, Backup
  - Easy filtering & management

- 🧩 **LeetCode Tracker**
  - Add problems with difficulty & topic
  - Track solved vs unsolved
  - Filter by difficulty/status

- 📝 **Interview Notes**
  - Save interview experiences
  - Track rounds & outcomes (Selected / Rejected / Pending)

- ⏳ **Mock Interview Scheduler**
  - Schedule mock interviews
  - Countdown tracking
  - Mark as completed

- 📖 **Daily Notes**
  - Write daily progress
  - View last 7 days history

- 💾 **Local Storage आधारित**
  - No backend required
  - Works offline
  - Data stays in your browser

---

## 🛠️ Tech Stack

- HTML5  
- CSS3 (Modern UI, gradients, animations)  
- Vanilla JavaScript  
- LocalStorage (Data persistence)
